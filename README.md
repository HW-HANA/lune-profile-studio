# Lune Profile Studio

## 小红书介绍

### Lune｜把你的日常排版成一张好看的主页图

一个轻量、好玩的社交主页视觉编辑器。

不用设计基础，上传头像、封面和动态图片，选择喜欢的主题与字体，就能制作一张属于自己的主页卡片。图片可以单独裁切，文字、颜色、布局和动态内容都能随时调整，最后导出 PNG 或 JPG 保存、分享。

适合制作：

- 个人社交主页展示图
- 动态记录与生活相册
- 头像、封面和主页视觉排版
- 小红书、朋友圈和个人资料页配图

## 功能

- 社交主页模式与纯动态模式
- 头像、封面和每张动态图片单独裁切
- 拖动图片选择显示区域，支持缩放和重新编辑
- 柔雾粉、明亮、夜间主题与自定义配色
- 主页底色、按钮、文字、封面、头像、标签等颜色独立调整
- 上传 WOFF2、WOFF、TTF、OTF 字体
- 动态文字、图片、时间和互动数据编辑
- 固定比例动态布局，避免自由排版后变形
- PNG / JPG 导出，可选择是否包含画布背景与留白
- 项目备份与恢复
- 撤销、重做和浏览器本地自动保存
- 支持电脑和手机浏览器

## 在线使用

部署后的静态网址可以直接打开使用。项目数据和上传字体保存在当前浏览器本地，不会自动同步到其他设备。

## 本地运行

需要 Node.js。

```sh
pnpm install
pnpm dev
```

打开：<http://127.0.0.1:5175/>

也可以双击 `Start-Lune.cmd` 启动已构建版本。

## 构建

```sh
pnpm build
```

构建结果位于 `dist/`，可以部署到 Netlify、Cloudflare Pages、Vercel、GitHub Pages 等静态托管服务。

## Netlify 部署

连接 GitHub 仓库后填写：

```text
Build command: pnpm build
Publish directory: dist
```

## 数据与隐私

- 上传的图片和字体只保存在当前浏览器的本地存储中。
- 字体不会被打包进网页，也不会自动上传服务器。
- 清除浏览器站点数据后，本地草稿和上传字体会被删除。
- 可以使用“备份项目”导出 JSON 文件，再通过“恢复项目”重新载入。
