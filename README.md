# Lune Profile Studio · 独立主页版

仅保留社交主页、纯动态、动态编辑、外观设置及导出作品历史，无聊天编辑器或灵感模板页面。

编辑器顶部可切换「社交主页」和「纯动态」。纯动态只输出动态流，隐藏封面、头像主页头部、简介、标签和资料信息；动态内容、裁切、主题、字体、画布和导出功能保持可用。模式会自动保存，刷新或恢复项目后仍保持选择。

双击 `Start-Lune.cmd`，访问 http://127.0.0.1:5175/ 。启动需要 Node.js；启动器也支持本机 Codex 提供的 Node.js。已包含构建好的 dist，无需安装依赖即可启动。

## 自定义主题

预设和自定义现在使用相同的配色规则。先选预设再点「自定义」，会完整复制当前预设颜色。支持独立调整主页底色、按钮与强调色、正文、默认封面、默认头像底色、头像图标、标签底色、标签文字、辅助文字、分隔线、按钮文字、认证标识，共 12 项不透明颜色。颜色即时更新、自动保存，并应用到 PNG/JPG 导出。画布背景单独设置。

新作品默认使用柔雾粉主题、图标头像与纯色封面。旧版本附带的示例头像/封面自动替换成默认样式，用户上传的图片保留。移除已上传的头像或封面后，将恢复可配色的默认样式。

「外观样式 → 字体」支持上传 WOFF2、WOFF、TTF、OTF，最大 20 MB；仅用于主页内容，支持本地持久化、备份恢复和导出嵌入。缺失中文字形时回退至系统字体。可点击「恢复默认字体」移除。

默认导出只保留主页内容，PNG 圆角外透明；可选包含背景与留白。支持作品备份/恢复、撤销/重做、动态排序与图片上传。

独立版使用自己的地址和 IndexedDB 数据库，不读取或覆盖原版作品。可从原版导出主页 JSON 备份，再在此版本恢复；聊天项目不支持导入。

## 图片裁切

上传头像、封面或动态图片时，会立即打开单张图片的裁切窗口。直接拖动图片选择露出区域，使用滚轮或加减按钮缩放，再点「确定裁切」。头像显示圆形取景框，封面与动态图片的取景框匹配实际显示比例。

点击编辑器里的图片缩略图，或直接点击主页预览里的头像、封面、单张动态图片，都能重新裁切。每张动态图片分别保存位置和缩放；没有上下左右滑块，也没有多张图片共用的调节器。动态网格由布局固定；添加或删除图片后可再次点击某张图片调整取景。

取消、Esc 或关闭窗口会放弃本次修改，上传替换也只在确认后生效。原图始终保留，可重置、撤销/重做、自动保存和备份恢复。PNG/JPG 导出使用相同的裁切数据。手机支持单指拖动，按钮缩放；键盘也可聚焦裁切预览后使用方向键微调。

## 开发与验证

```sh
pnpm install
pnpm dev
pnpm build
```

`dist/` 可部署到静态托管。测试：先启动本地服务器，再运行 `pnpm exec playwright test`。移动测试使用浏览器模拟视口，未做真机验收。
